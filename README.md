no# RTL433-Acurite-Bridge

A modern Home Assistant add-on that bridges **rtl_433** weather station data into Home Assistant using MQTT Discovery.

## Features

- 📡 Supports RTL-SDR receivers
- 🌦️ Designed for Acurite weather stations
- 🏠 Home Assistant MQTT Discovery
- 📶 MQTT Broker Support
- 🔍 Device Whitelist
- 📊 Friendly Entity Names
- 🔄 Multi-Architecture Builds
- 📜 Open Source (MIT)
